# composition-maker（組成表・棒グラフ作成アプリ）

EDS の定量結果レポート（Word / txt / csv）から、元素・原子%・質量%だけを取り出して、
Word や PowerPoint にそのまま貼り付けられる表と棒グラフを作るアプリです。

データは自分の PC の中だけで処理します。外部には送信しません。

## できること

- Oxford AZtec の EDS レポート（.docx）や、表をコピーしたテキスト（.txt / .csv / 貼り付け）を読み込む
- ラインタイプ、k レシオ、標準試料などの不要な列を捨て、元素・原子%・質量%・σ だけの表にする
- 原子%の列がないレポートでも、質量%から原子量で換算する
- 元素を除外して残りを 100% に再規格化する（例：O を除いてカチオン比を見る）
- 複数のスペクトルを並べ、平均と標準偏差を出す
- 表を「表をコピー」ボタンで Word・PowerPoint に貼り付ける（三線表または格子罫線）
- 元素ごとの棒グラフを PNG（300 dpi）で保存する

初期表示は原子%（at%）のみです。質量%や σ はサイドバーの「項目」で追加します。

## はじめて使うとき

Python 3.9 以降が必要です。ターミナル（Windows は PowerShell）で次を実行します。

```
git clone https://github.com/A-Okawa/composition-maker.git
cd composition-maker
pip install -r requirements.txt
```

## 起動

```
streamlit run app.py
```

ブラウザが自動で開きます。開かないときは、ターミナルに表示される `http://localhost:8501` を開いてください。
終了するときは、ターミナルで Ctrl+C を押します。

## 更新

```
cd composition-maker
git pull
```

## 使い方

1. 左の「読み込み」に EDS レポートをドロップする（複数可）。または表をコピーして貼り付ける。
2. 「読み込んだスペクトル」で、表に載せる名前を直し、含めるものにチェックを入れる。
3. サイドバーで項目（原子%・質量%・σ）、除外する元素、小数桁、体裁を選ぶ。
4. 「表をコピー」を押して、Word や PowerPoint に貼り付ける。
   うまくコピーされないときは、表が選択された状態になるので Ctrl+C（Mac は ⌘C）でコピーする。
5. 棒グラフは、画像を右クリックしてコピーするか、PNG をダウンロードする。

## 注意

- 原子%は、質量%を原子量で換算した値です。レポートに原子%の列があっても、表示は質量%からの換算値で統一します。
- 元素を除外すると、質量%・σ・原子%はすべて残りの元素で 100% に再規格化されます。
- 平均・標準偏差では、あるスペクトルで検出されていない元素を 0 として計算します。
- 読み込めるのは、見出しに「元素（Element）」と「質量%（Wt%）」または「原子%（At%）」がある表です。
  読み込めない形式のファイルがあれば、大川まで連絡してください。
- WDS の出力は、まだ実際のファイルで確認していません。
